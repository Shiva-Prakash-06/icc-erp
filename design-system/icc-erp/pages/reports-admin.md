# Reports and Administration Override

Inherits `MASTER.md`.

- Reports emphasize reading, provenance, scope, generated time, and export actions.
- Print is a first-class state; decorative shell elements are absent.
- Administration uses opaque surfaces only. Approval/rejection/role changes receive explicit scope summaries.
- Destructive/reject actions are separated spatially and require confirmation when irreversible.
- Audit/checksum/code columns use data typography, wrap or copy affordance, and never truncate without access to the full value.

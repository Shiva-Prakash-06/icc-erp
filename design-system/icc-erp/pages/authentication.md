# Authentication Override

Inherits `MASTER.md`.

- Maximum form width 440px; reading line length 55 characters.
- Ambient background may use two blurred static color fields at ≤10% opacity; no 3D interaction.
- Password fields include show/hide controls with accessible labels.
- Login primary action is full width. Registration and recovery links are secondary text links.
- Server error summary appears before the first field and focuses after submission.
- Autofill, password managers, 400% zoom, and mobile keyboard must not cover the primary action.
